# 💍 ALY & MENNA — Interactive Engagement Invitation

> دعوة خطوبة رقمية تفاعلية حديثة وخاصة بحفل خطوبة **علي فرجاني & منة أشرف (ALY & MENNA)**.

---

## ✨ المميزات الرئيسية (Key Features)

* **تصميم شبابي وتفاعلي (Scroll-Driven UX):**
  * شريط تقدم القراءة المتدرج بلون مرجاني حيوي.
  * تأثيرات حركية متناسقة عند التمرير وإضاءات خلفية هادئة.
  * بطاقة تفاعلية ثلاثية الأبعاد للتبديل بين كارت الدعوة وصورة العروسين مع ميزة النقر المزدوج (Double Tap Heart).
* **عداد تنازلي دقيق ومتزامن:**
  * عداد تنازلي حي في واجهة الموقع وداخل فيديو الريل متطابق لحظياً بالثواني حتى موعد الحفل (السبت 5 ديسمبر 2026 الساعة 02:00 ظهراً بتوقيت القاهرة).
* **تجميع التهاني وتأكيدات الحضور داخل الموقع (On-Site RSVP & Guestbook):**
  * نموذج تأكيد حضور وحفظ التهاني محلياً وعرضها فوراً في لوحة أمنيات الضيوف المباشرة دون الحاجة للتحويل لتطبيقات خارجية.
  * عدادات حقيقية وواقعية بالكامل تظهر الحضور المؤكد الفعلي بدون أرقام وهمية.
  * ميزة تصدير كشف الحضور والتهاني للعروسين إلى ملف Excel / CSV مع دعم كامل لترميز اللغة العربية (UTF-8 BOM).
* **موسيقى خلفية مخصصة:**
  * تحكم بالموسيقى الخلفية (*Ed Sheeran - Perfect*) مع تأثيرات صوتية وتفاعلية.
* **شريط سفلي عائم سريع (Floating Quick Dock):**
  * وصول سريع للتحكم بالصوت، إرسال تبريكات، فتح خريطة القاعة، وتأكيد الحضور.
